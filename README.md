# STEAMLabs Africa 2026 Annual Report Form

This is a static HTML website. Vercel serves `index.html` directly; no `index.js`,
build command, framework preset, or output directory is required.

## Deploy to Vercel
1. Upload this folder to a GitHub repository, or import the repository in Vercel.
2. In Vercel, choose **Other** as the Framework Preset if prompted.
3. Leave Build Command and Output Directory empty.
4. Deploy.

The form retains the Google Apps Script Web App URL from the supplied source.
The form also stores drafts and CSV exports in the visitor's browser.
